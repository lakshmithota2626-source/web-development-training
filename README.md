## 🛠️ Tech Stack & Methodologies
- **Core Languages:** Semantic HTML5, Vanilla CSS3, JavaScript (ES6+)
- **Architecture:** Modular, Component-based separation of concerns
- **Libraries:** jQuery 3.7.1 & jQuery UI 1.13.2
- **Networking:** Fetch API, AJAX, REST APIs, JSON Parsing
- **Design:** Dark Mode, Glassmorphism, CSS Custom Properties, Keyframe Animations, Mobile-First Responsive Grids
