Exercise 1 A-E

Five small problems practise values, decisions, loops, arrays, objects, and DOM events.

Prompt note: The original Exercise 1 A-E worksheet was not in the repository. These are mentor-authored practice prompts aligned with the Day 3 topics, not a transcription of the original assignment.

A. Tip calculator

Given a bill amount and tip percentage, calculate the tip and the final total. Use numeric variables, arithmetic, and a function.

Tip: $6.00 | Total: $46.00

Practice variation: add a number-of-people field and calculate each person's share.

B. Score band

Classify a score from 0 to 100 using an if/else chain. Reject values outside the allowed range.

Grade: B

Practice variation: add a separate message for scores below 50.

C. Loop and multiples

Use a loop to list numbers from 1 to a chosen limit that are divisible by 3.

3, 6, 9, 12

Practice variation: list multiples of both 3 and 5 with a different message for common multiples.

D. Analyze quiz scores

Read a comma-separated score list, keep passing scores (60 or higher), and calculate the average with array methods.

Passing: 67, 82, 91 | Average: 73.8

Practice variation: show the highest score and the number of scores below 60.

E. Reading list DOM

Create an object from a form, append it to an array, render the list, and remove a row through event delegation.

Two sample books are ready.

    Practice variation: add a read/unread status and a button to toggle it.
