Function Syntax Comparison

  • Normal Function: function add(a, b) { return a + b; }
  • Anonymous: const add = function(a, b) { return a + b; };
  • Arrow (ES6): const add = (a, b) => a + b;
  • Callback: A function passed into another function as an argument.
  • Higher-Order: A function that takes or returns functions.
