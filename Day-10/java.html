01 / Foundations

Java and its building blocks

Java is a general-purpose, class-based language. The basics are statements, values, and types.

01

Introduction to Java

Java is a general-purpose, class-based language. A compiler turns source code into bytecode that the JVM can run.

Program shape

public class HelloJava {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}

Expected output

Hello, Java!

The JVM starts at main and prints one line.

Use: command-line tools, desktop and server applications, Android development, and more.

02

Java syntax

Java uses classes and methods. Statements usually end with a semicolon, and braces mark code blocks.

Syntax

class Example {
    public static void main(String[] args) {
        // statements go here
    }
}

Runnable example

System.out.println("Ready");

Output: Ready

The print statement runs inside the main method.

Use: follow the structure so the compiler can check and run your program.

03

Variables

A variable is a named place to keep a value. Its type is declared before its name.

Syntax

type variableName = value;

Java example

int score = 92;
score = 96;
System.out.println(score);

Output: 96

The variable is reassigned before it is printed.

Use: keep track of values such as a score, quantity, or user name.

04

Data types

Types determine what a value represents and which operations are valid. Java has primitive types and reference types such as String.

Common types

int count = 4;
double price = 2.5;
char grade = 'A';
boolean ready = true;
String language = "Java";

Expected output

4 2.5 A true Java

Each variable stores a value suited to its declared type.

Use: choose types that describe the data your program needs.

05

Operators

Operators calculate values, compare values, and combine boolean conditions.

Syntax

+  -  *  /  %
==  !=  >  <  >=  <=
&&  ||  !

Java example

int total = 12 + 5;
int remainder = total % 4;
boolean enough = total >= 15;
System.out.println(total + " " + remainder + " " + enough);

Output: 17 1 true

Arithmetic calculates numbers; comparison returns a boolean.

Use: compute totals and make decisions from values.

02 / Control flow

Choose a path or repeat work

Conditions choose which statements run; loops repeat statements while their rules allow it.

06

if / else

An if statement runs a block when its boolean condition is true. else handles the other path.

Syntax

if (condition) {
    // true path
} else {
    // other path
}

Java example

int score = 74;
if (score >= 60) {
    System.out.println("Pass");
} else {
    System.out.println("Try again");
}

Output: Pass

Because 74 is at least 60, the first branch runs.

Use: validate input or choose a message based on a value.

07

switch

A switch selects one branch from a set of matching cases. Use break to leave a case.

Syntax

switch (value) {
    case option:
        // work
        break;
    default:
        // fallback
}

Java example

String day = "MON";
switch (day) {
    case "MON":
        System.out.println("Start");
        break;
    default:
        System.out.println("Other day");
}

Output: Start

The matching case runs, then break exits the switch.

Use: handle menu choices or a known set of categories.

08

for loop

A for loop is useful when you know the starting value and the stopping condition.

Syntax

for (start; condition; update) {
    // repeated work
}

Java example

for (int number = 1; number <= 3; number++) {
    System.out.println(number);
}

Output: 1, then 2, then 3

The loop increments number after each pass.

Use: repeat a task a set number of times.

09

while loop

A while loop checks its condition before each pass. It may run zero times if the condition starts false.

Syntax

while (condition) {
    // update toward stopping
}

Java example

int count = 2;
while (count > 0) {
    System.out.println(count);
    count--;
}

Output: 2, then 1

The counter decreases so the condition eventually becomes false.

Use: repeat while a condition remains true.

10

do-while loop

A do-while loop checks its condition after the body, so it always runs at least once.

Syntax

do {
    // repeated work
} while (condition);

Java example

int attempts = 0;
do {
    attempts++;
    System.out.println(attempts);
} while (attempts < 1);

Output: 1

The body runs once, then the false condition stops the loop.

Use: show a menu at least once before checking whether to repeat.

03 / Reusable data and behavior

Arrays and methods

Arrays group values of the same type. Methods give a name to reusable behavior.

11

Arrays

An array stores a fixed number of values of one declared type. Its first index is 0 and its length is available through length.

Syntax

int[] values = {value1, value2};
values[0];
values.length;

Java example

int[] scores = {80, 95, 70};
int total = 0;
for (int score : scores) {
    total += score;
}
System.out.println(total);

Output: 245

The enhanced for loop adds every score to total.

Use: store and process a group of scores, prices, or other same-type values.

Complete runnable program: ArrayDemo.java
12

Methods

A method is a named block of code. Parameters receive inputs, and a return type describes its result.

Syntax

static returnType methodName(parameters) {
    return result;
}

Java example

static int add(int left, int right) {
    return left + right;
}

System.out.println(add(4, 5));

Output: 9

Calling add passes two numbers and prints the returned sum.

Use: avoid repeating calculations and give an operation a clear name.

Complete runnable program: BasicsDemo.java

04 / Object-oriented programming

Classes, objects, and OOP

Classes describe a type of object. Constructors create initialized objects; OOP organizes data and behavior together.

13

Classes

A class is a blueprint that declares the data and behavior its objects can have.

Syntax

class Person {
    private String name;
    String getName() { return name; }
}

Java example

class Person {
    private final String name;
    Person(String name) { this.name = name; }
    String getName() { return name; }
}

Result: defines a type with a private field and a method.

The class groups a person's data with behavior for reading it.

Use: model concepts such as a person, product, or bank account.

Complete runnable program: OopDemo.java
14

Objects

An object is an instance of a class. Each object has its own field values.

Syntax

ClassName variable = new ClassName(arguments);

Java example

Person learner = new Person("Sam");
System.out.println(learner.getName());

Output: Sam

The variable refers to one Person object.

Use: represent individual records with their own values.

Complete runnable program: OopDemo.java
15

Constructors

A constructor runs when an object is created. It has the class name and no return type.

Syntax

ClassName(parameters) {
    // initialize fields
}

Java example

Person(String name) {
    this.name = name;
}

Person learner = new Person("Sam");

Result: the new person's name is initialized to Sam.

this.name refers to the object's field.

Use: ensure a new object starts with required values.

Complete runnable program: OopDemo.java
16

Basic OOP concepts

Encapsulation protects fields, abstraction exposes a simple contract, inheritance reuses a parent type, and polymorphism allows an override to vary behavior.

Syntax

class Student extends Person {
    @Override
    String introduce() { ... }
}

Java example

Member learner = new Student("Leo", "Java");
System.out.println(learner.introduce());

Output: I'm Leo, a Java student.

The parent reference calls the student's overridden method.

Use: organize related types while keeping each type's behavior clear.

Complete runnable program: OopDemo.java
