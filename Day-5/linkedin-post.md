# Day 5 LinkedIn Post: Tic-Tac-Toe

Day 5 of my Web Development Training gave me a chance to practise game logic through the Tic-Tac-Toe project.

The existing game supports two-player play and a computer opponent, with turn tracking, win/draw detection, a scoreboard, and restart controls. I used it to think through how game state changes after each move and how the interface communicates the result.

Small projects like this make programming logic easier to inspect and test.
