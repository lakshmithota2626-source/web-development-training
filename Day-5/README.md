# Day 5: L'AURA Artisan Bistro — Restaurant Menu Website

Welcome to **Day 5** of Web Development Training! Today covers building a modern, luxury restaurant menu website with interactive menu filtering, dietary tags, dynamic cart management, and table reservation workflows.

---

## 📂 File Structure

```text
Day-5/
├── index.html    # Semantic structure for restaurant showcase, menu & modal views
├── style.css     # Luxury warm dark slate & gold theme, responsive layout
├── script.js     # Dynamic menu filtering, interactive cart & reservation controller
└── README.md     # Project documentation
```

---

## 🍽️ Features Included

1. **Brand & Navigation**:
   - Distinctive typography (`Playfair Display` serif & `Plus Jakarta Sans`).
   - Sticky glassmorphism header with navigation links and instant cart indicator.
2. **Hero & Story**:
   - Michelin-recognized artisan branding and farm-to-table culinary philosophy.
3. **Interactive Menu & Category Filtering**:
   - **Categories**: *All Dishes*, *Starters & Tapas*, *Chef's Mains*, *Woodfired & Pasta*, *Artisan Desserts*, *Cocktails & Elixirs*.
   - **Real-Time Search Bar**: Instant filtering across dish titles and culinary ingredients.
   - **Dietary Toggles**: Filter by 🌿 Vegetarian, 🌶️ Spicy, and ⭐ Chef's Pick.
4. **Food Item Cards**:
   - Visual food emoji/icon badges, Chef's badges, price tags, descriptions, allergen/dietary pills, ratings, and instant "+ Add to Order" buttons.
5. **Slide-Out Order Cart Drawer**:
   - Smooth slide animation from right.
   - Item quantity increment/decrement (`+` / `-`), auto-calculation of subtotal, 8% sales tax, and grand total.
   - Interactive checkout modal with order reference numbers.
6. **Table Reservation System**:
   - Date, time, party size, and special preferences form with confirmation receipt modal.
7. **Comprehensive Footer**:
   - Operating dining hours, location, contact, and social channels.
8. **100% Mobile & Tablet Responsive**:
   - Custom breakpoints for smooth viewing on any device.
