# Day 13 LinkedIn Post: React Project 2

I completed React Project 2: Pantry Ledger, a small inventory app for tracking pantry items, quantities, categories, and best-before dates.

While building it, I practised JSX, components, props, state, controlled forms, event handling, lists, conditional rendering, and array methods for searching and filtering. I also used local storage so pantry changes remain in the browser between visits.

One challenge was keeping the summary counts, item statuses, filters, and saved data in sync as the list changed. This helped me understand how React state can drive several parts of an interface.

Next, I want to learn component testing and add tests for the form and filtering behavior.
