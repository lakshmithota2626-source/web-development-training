01

What Redux is

Redux in one sentence

Redux is a predictable state container for JavaScript applications. It helps us keep data in one place and makes updates easier to track, debug, and test.

Core idea

Instead of storing state in many different components, the app keeps state in one central store and updates it through clear rules.

02

Why state management is needed

Without a central store

  • State is duplicated across many components.
  • Updates become hard to predict.
  • Debugging gets messy.
  • Different parts of the app can get out of sync.

With Redux

  • One source of truth for app data.
  • Clear rules for updating state.
  • More predictable behavior.
  • Easier debugging and testing.
Think of it like this: Without a shared state system, your app can feel like several people editing the same document at the same time.

05

Reducers

function counterReducer(state = { count: 0 }, action) {
  switch (action.type) {
    case 'COUNTER_INCREMENT':
      return { ...state, count: state.count + 1 };
    default:
      return state;
  }
}
Reducers are pure functions: same input, same output. They do not randomly change things or trigger network calls.

Client vs Server

Client

  • Runs in the browser.
  • Handles UI and interaction logic.
  • Requests data from a server.

Server

  • Runs on a backend system.
  • Stores data and processes requests.
  • Sends a response back to the client.

13

Loading, Success and Error states

Loading

Show a spinner or placeholder while waiting for the server response.

Success

Render the fetched data and show the result clearly.

Error

Show the message and provide a retry option when something fails.

A strong app responds clearly to all three states so users always know what is happening.
