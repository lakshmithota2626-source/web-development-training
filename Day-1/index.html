Core Concepts Explained

Master these six fundamental pillars of client-server architecture.

👤
01

1. Client

The Client is the device, browser, or software application that requests resources or services from a server.

  • Examples: Google Chrome, Safari, mobile apps, or command line tools like curl.
  • Role: Captures user actions (clicks, form inputs), packages them into requests, and renders the received server responses.
🖥️
02

2. Server

The Server is a powerful computer or program that continuously listens for incoming client requests, processes logic, and returns requested resources.

  • Examples: Nginx, Apache, Node.js/Express, Python/Django, Cloud servers.
  • Role: Hosts files (HTML, CSS, images), manages databases, handles business logic, and ensures data security.
📤
03

3. Request

An HTTP Request is the formatted message sent by the client to ask the server to do something.

Method (GET, POST, PUT, DELETE)
URL / Endpoint
Headers (User-Agent, Content-Type)
Body (Data payload for POST/PUT)
📥
04

4. Response

An HTTP Response is the reply sent back by the server answering the client's request.

Status Codes (200 OK, 404 Not Found, 500 Error)
Headers (Content-Length, Cache-Control)
Body (HTML file, JSON data, Image stream)
🔐
05

5. HTTP vs. HTTPS

HTTP (Hypertext Transfer Protocol) transfers data as plain text. HTTPS adds an encrypted SSL/TLS layer.

HTTP (Port 80) Unencrypted — readable by eavesdroppers
HTTPS (Port 443) Encrypted & Secure — protects passwords and sensitive data
🔄
06

6. Basic Request-Response Lifecycle Flow

Here is what happens step-by-step when a user types https://example.com into a browser:

Step 1

User Action

User enters URL or clicks a link in the browser.

Step 2

DNS Resolution

Browser converts domain name into a server IP address.

Step 3

TCP / SSL Handshake

A reliable connection is established between client & server.

Step 4

Client Sends Request

Browser sends HTTP GET request with headers and parameters.

Step 5

Server Processes

Server executes code, queries database, and prepares response.

Step 6

Response & Render

Server sends back HTML/CSS/JS; browser renders UI.
