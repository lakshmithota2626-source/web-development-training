# Day 1: Understanding Client-Server Communication

Welcome to **Day 1** of Web Development Training! Today's focus is understanding how the web works behind the scenes through the **Client-Server Architecture**.

---

## 📚 Topics Covered

1. **Client**: The device or application (like a browser) making requests.
2. **Server**: The central computer/system storing data and handling requests.
3. **Request**: The message sent from the client asking for resources or performing actions.
4. **Response**: The message sent back by the server with data and status information.
5. **HTTP vs. HTTPS**: Protocols governing communication, including encryption (SSL/TLS).
6. **Basic Request-Response Lifecycle**: The step-by-step journey from entering a URL to viewing a web page.

## 💡 Key Takeaways

- **Clients** initiate interactions; **Servers** listen and respond.
- A **Request** contains: Method (`GET`, `POST`, `PUT`, `DELETE`), URL/Path, Headers, and optional Body.
- A **Response** contains: Status Code (e.g., `200 OK`, `404 Not Found`), Headers, and Body (HTML, JSON, etc.).
- **HTTPS** encrypts requests and responses, ensuring data privacy and security over the internet.
