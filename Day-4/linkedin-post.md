# Day 4 LinkedIn Post: NEXUS Event Invitation

For Day 4 of my Web Development Training, I revisited the NEXUS event invitation website and the skills used to make an event page interactive.

The project uses semantic HTML, responsive CSS, JavaScript interactions, a countdown, schedule and speaker sections, and an RSVP pass flow. I also practised JavaScript OOP, jQuery events, jQuery UI, and AJAX/Fetch concepts in the Day 4 learning suite.

This work helped me see how separate frontend tools can support one cohesive web experience.
