1. CSS Selectors

Techniques used to target specific HTML elements for styling.

Universal Selector (*)

Matches every single element in the document tree. Often used for CSS resets.

* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
Every element inside is targeted

Element Selector (p, h2)

Targets all HTML elements matching the specific tag name.

p {
  color: #38bdf8;
  line-height: 1.5;
}

This paragraph is styled by an element selector.

ID Selector (#header)

Targets a unique element with a specific id attribute (highest specificity).

#uniqueBadge {
  background: #f43f5e;
  padding: 6px 12px;
}
Unique Element (#uniqueBadge)

Class Selector (.card)

Targets all elements with the specified class name. Reusable across the page.

.highlight-pill {
  background: #10b981;
  color: #fff;
  border-radius: 20px;
}
Reusable Class Badge

Descendant Selector (.parent .child)

Matches all elements nested inside a parent element at any depth.

.parent-box .nested-text {
  color: #fbbf24;
  font-weight: bold;
}
Nested descendant styled with amber highlight

Attribute Selector ([type="..."])

Targets elements based on the presence or value of an HTML attribute.

input[type="text"][data-status="active"] {
  border: 2px solid #a855f7;
}

11. Media Queries & Responsive Design

Adapt layouts dynamically across mobile, tablet, desktop, and large displays.

Mobile-First (min-width) vs Desktop-First (max-width)

Standard responsive design breakpoints using clean CSS media queries.

/* Base styles apply to mobile first */
.responsive-box {
  width: 100%;
  background: #3b82f6; /* Mobile: Blue */
}

/* Tablet: >= 640px */
@media (min-width: 640px) {
  .responsive-box { background: #8b5cf6; } /* Tablet: Purple */
}

/* Desktop: >= 1024px */
@media (min-width: 1024px) {
  .responsive-box { background: #10b981; } /* Desktop: Green */
}
Mobile (<640px) Tablet (640-1023px) Desktop (≥1024px)

Resize browser window to observe live breakpoint changes!

Auto-fit grid columns avoiding rigid media queries where possible.

CSS Variables & Relative Units

Define dynamic design tokens with --variable-name and relative units (rem, em, vh, vw, %).

:root {
  --brand-color: #f97316;
  --spacing-base: 1rem; /* 16px relative to root */
}

.custom-token-box {
  background: var(--brand-color);
  padding: calc(var(--spacing-base) * 0.75);
  font-size: 1.1rem;
}
