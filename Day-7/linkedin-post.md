# Day 7 LinkedIn Post: Self-Designed React Portfolio

For Day 7 of my Web Development Training, I built a self-designed React learning portfolio.

The page brings together an About section, skills I have practised, repository-backed projects, a training journey, and a demo contact form. I used React components and props to keep the sections reusable, and state to handle the form's preview response.

The form is front-end only and does not send messages. I left personal contact and LinkedIn details for me to add before sharing the page publicly.

This was useful practice in turning React topics into a responsive page with a clear structure.
