01

What Redux is

Redux in one sentence

Redux is a predictable state container for JavaScript apps. It helps keep data in one place and makes updates easier to track.

Core idea

Instead of spreading state across many components, Redux stores it in one central location called the store.

02

Why state management is needed

Without a central store

  • State can be duplicated across many components.
  • Updates become hard to predict.
  • Debugging and testing become frustrating.
  • Different parts of the app can drift out of sync.

With Redux

  • One source of truth for app data.
  • Clear rules for updating state.
  • Better debugging and time-travel style tracing.
  • Predictable app behavior.
Think of it like this: without a shared state system, your app can feel like multiple people changing the same document at the same time.

05

Reducers

function counterReducer(state = { count: 0 }, action) {
  switch (action.type) {
    case 'COUNTER_INCREMENT':
      return { ...state, count: state.count + 1 };
    default:
      return state;
  }
}
Reducers are pure functions: same input, same output. No random values or API calls inside them.

09

Client vs Server

Client

  • Runs in the browser.
  • Handles UI, interactions, and local state.
  • Requests data from a server.

Server

  • Runs on a backend system.
  • Stores and processes data.
  • Sends responses back to the client.

13

Loading, Success and Error states

Loading

Show spinner while waiting for the server response.

Success

Render the fetched data and update the view.

Error

Display a message and offer retry options.

A strong app handles all three states clearly so users always know what is happening.
