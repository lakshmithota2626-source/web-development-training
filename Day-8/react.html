The building blocks

Six ideas to know first

Each concept has a small job. Together, they describe an interactive interface.

01 / JSX

UI written like markup

JSX lets you write HTML-like syntax in JavaScript. A build tool transforms it into JavaScript calls.

02 / Components

Reusable UI pieces

A component is a function that returns part of the interface, such as a profile card or a button.

03 / Props

Inputs from a parent

Props pass information into a component. A component reads props but should not change them.

04 / State

Data that can change

State stores values that change over time. Updating state asks React to render the component again.

05 / Events

Respond to people

Event handlers such as onClick and onChange connect user actions to state updates.

06 / Hooks

React features in functions

Hooks like useState and useEffect let function components use state and synchronize with outside systems.

Read the shape

A component with props

Greeting.jsx
function Greeting({ name }) {
  return (
    <section>
      <h2>Hello, {name}!</h2>
      <p>Welcome to React.</p>
    </section>
  );
}

<Greeting name="Sam" />

What is happening?

Greeting is a component. Its name starts with a capital letter so React can distinguish it from a built-in HTML tag.

name is a prop passed by the parent. The component uses it to create a personalized heading.

JSX looks like HTML, but it is JavaScript syntax transformed before the browser runs it.

Find the React pieces

  • Component: ProfilePreview and CounterLab return UI.
  • Props: the parent passes the current name to ProfilePreview.
  • State: useState remembers the name and count.
  • Events: typing and clicking call state setter functions.
  • Effect: useEffect updates the browser tab title when the count changes.
