# Redux & Client–Server Communication

A beginner-friendly interactive frontend project that explains Redux, state management, client-server communication, HTTP methods, async API flows, and the concept of `createAsyncThunk`.

## Features
- Modern responsive learning dashboard
- Redux overview and state management explanations
- Interactive Redux-inspired counter example
- Request and response simulation
- HTTP method examples for GET, POST, PUT, and DELETE
- Async loading, success, and error states
- Dark and light mode toggle
- Slide-by-slide navigation with previous and next controls
- Progress indicator and keyboard navigation
- Interactive quiz with scoring and feedback

## Technologies used
- HTML5
- CSS3
- Vanilla JavaScript

## Folder structure
```text
Day-8-Redux/

```

## How to run
1. Open the `Day-8-Redux` folder in VS Code.
2. Open `index.html` in a browser, or use a live preview extension.
3. The project works fully offline with no backend or API key required.

## What I learned
- Redux keeps application state predictable and centralized.
- Actions describe events and reducers update state in a controlled way.
- Dispatch is how events are sent into the Redux flow.
- `useSelector` helps components read only the data they need.
- Client-server communication depends on HTTP requests and responses.
- Async flows require clear loading, success, and error handling.
- Real-world apps use Redux and async state patterns to keep interfaces reliable.
